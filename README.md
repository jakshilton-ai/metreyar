# متره‌یار

دستیار فارسی متره، برآورد مصالح و هزینه ساختمان؛ قابل نصب به‌صورت وب‌اپ (PWA).

## امکانات فعلی
- محاسبه دیوارچینی، بتن‌ریزی، میلگرد، خاموت، کاشی و سرامیک، خاک‌برداری، سفیدکاری، رنگ‌آمیزی و قوطی و پروفیل
- جداول مرجع مصالح و راهنمای روش محاسبه
- ذخیره برآوردها در دفتر پروژه روی دستگاه
- خروجی CSV سازگار با Microsoft Excel و پشتیبان/بازیابی JSON
- حالت روشن/تیره، چاپ و کارکرد آفلاین با Service Worker

## استفاده
پروژه را روی GitHub Pages یا هر میزبان استاتیک HTTPS منتشر کنید و از مرورگر گزینه نصب برنامه را انتخاب کنید. اطلاعات دفتر پروژه در حافظه محلی همان مرورگر ذخیره می‌شود؛ برای انتقال دستگاه از پشتیبان JSON استفاده کنید.

> ضرایب متره و قیمت‌ها تخمینی هستند و باید با نقشه‌ها، مشخصات فنی و نرخ روز پروژه تطبیق داده شوند.
