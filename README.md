# متره‌یار

دستیار فارسی متره، برآورد مصالح و هزینه ساختمان؛ قابل نصب به‌صورت وب‌اپ (PWA).

## امکانات فعلی
- محاسبه دیوارچینی، بتن‌ریزی، میلگرد، خاموت، کاشی و سرامیک، موزاییک کف، فوم بتن، خیز هندسی مثبت و منفی دال، خاک‌برداری، سیمانکاری، رنگ‌آمیزی، قوطی و پروفیل
- برآورد کیسه سیمان و ماسه موردنیاز ملات بستر در ابزارهای موزاییک و سرامیک کف، با امکان تغییر ضخامت و نسبت مصرف
- ابزارهای برق ساختمان: برآورد متراژ سیم‌کشی و محاسبه اولیه بار و جریان تک‌فاز
- موسیقی آرام اختصاصی و اختیاری با تولید صدای داخلی مرورگر (بدون فایل یا پخش خودکار)
- جداول مرجع مصالح و راهنمای روش محاسبه
- ذخیره برآوردها در دفتر پروژه روی دستگاه
- خروجی Excel با قالب XLS سازگار با Excel، خروجی CSV و پشتیبان/بازیابی JSON
- جست‌وجو در برآوردها، تغییر نام پروژه، شمارنده پروژه‌ها و برآوردهای ذخیره‌شده
- حالت روشن/تیره، چاپ و کارکرد آفلاین با Service Worker

## استفاده
پروژه را روی GitHub Pages یا هر میزبان استاتیک HTTPS منتشر کنید و از مرورگر گزینه نصب برنامه را انتخاب کنید. دفتر پروژه امکان جست‌وجو و تغییر نام پروژه دارد و اطلاعات آن در حافظه محلی همان مرورگر ذخیره می‌شود؛ برای انتقال دستگاه از پشتیبان JSON استفاده کنید.

> ضرایب متره و قیمت‌ها تخمینی هستند و باید با نقشه‌ها، مشخصات فنی و نرخ روز پروژه تطبیق داده شوند.
